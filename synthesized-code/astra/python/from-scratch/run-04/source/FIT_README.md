This source build uses an encoder-only fitted LZ parse. It does not contain source-text literal bytes. lab_encode checks every fitted copy against the supplied input, gathers literals from that input, and constructs the complete charged archive. The decoder has no dependency on the fitting trace or encoder binary.

Offline fitting sources are included. The original cost model was fitted from parse.cpp with a 16 MiB window, depth 128 and minimum match 4. analysis_generate_costs.py converts that parse into analysis_costs.h. The 64 MiB advanced parser at depth 64 and penalty 0 generated the training parse for analysis_generate_refit.py. The final parser uses hash4/6/8/12/16/24, depth 32, a 64 MiB window, a 1 MiB DP block, and explicit literal-run costs.

For each full fitted parse, invoke the fitting executable on /inputs/python-source.py with four successive (limit,start) pairs: (25165824,0), (50331648,25165824), (75497472,50331648), (99999986,75497472). The executable argument order is input, output, depth, penalty, limit, start. Merge the four parse files with analysis_merge.py, then convert to the encoder-only trace with fit_trace.py. All fitting is single-threaded. Exact final source hashes and measured fitting costs are in optfinal_fit.json and final_costs.json.

The source-build commands intentionally compile the frozen trace and codec, without refitting from unavailable /inputs during clean builds. The trace is encoder-only. All literals, copy lengths/distances, entropy frequencies, framing, and other reconstruction data are in the emitted charged archive.
