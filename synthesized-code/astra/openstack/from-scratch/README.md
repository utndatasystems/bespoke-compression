# OpenStack · Astra · from scratch

Frozen codec folders and historical measurement/qualification records in `data/`
are retained. Run numbers identify independent submitted implementations. The
canonical submitted figures are in the [final figure map](../../../../paper/figures/README.md),
replacing the earlier draft plots.

Use the [root reproduction guide](../../../../REPRODUCING.md) to build and verify these
codecs with their original recipes, or to replay complete server measurements.
The per-run READMEs and provenance describe the original algorithm and conditions.
